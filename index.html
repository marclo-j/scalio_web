Conectar n8n a OpenCode vía MCP

Guía paso a paso de configuración para conectar tu instancia de n8n como servidor MCP remoto dentro de OpenCode.

01Requisitos previos

Antes de empezar, asegúrate de tener disponible lo siguiente.

  • Instancia de n8n activa — accesible desde el equipo donde se ejecuta OpenCode.
  • URL del servidor MCP — la URL del servidor MCP a nivel de instancia: url-server-instance-level-mcp.
  • OpenCode instalado — la herramienta desde la que cargarás el servidor remoto.
  • Token de autenticación — un token válido para el esquema Authorization: Bearer.

02Paso a paso

  1. 1

    Obtén la URL del servidor MCP de tu instancia. En n8n, localiza la URL que expone el servidor MCP a nivel de instancia: será el valor que sustituya a url-server-instance-level-mcp.

  2. 2

    Prepara tu token. Genera o copia el token de autenticación de la instancia: será el valor que sustituya a Bearer token.

  3. 3

    Abre la configuración de OpenCode. Localiza y abre el archivo de configuración de tu instalación.

  4. 4

    Agrega el bloque n8n. Pega el JSON de la sección 03 dentro de la configuración de servidores MCP remotos.

  5. 5

    Guarda y reinicia OpenCode. La nueva configuración se aplica al reiniciar la herramienta.

  6. 6

    Verifica la conexión. La entrada n8n debe figurar como servidor MCP remoto activo.

05Notas importantes

  • URL de la instancia. Reemplaza url-server-instance-level-mcp por la URL real del servidor MCP de tu instancia de n8n; el texto es un marcador de ejemplo.
  • Autenticación. Reemplaza Bearer token por tu token real, conservando el prefijo Bearer . Evita versionar el archivo con el token en claro.
  • Timeout. El valor de timeout está expresado en milisegundos: 30000 equivale a 30 segundos.
  • JSON válido. El bloque se muestra normalizado (sin comas finales) para ser JSON estricto válido; OpenCode lo interpreta sin tolerar comas finales.
